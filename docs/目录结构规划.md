# 页面与路由对应关系
页面	路由路径	说明
登录页	/login	登录
注册页	/register	注册
引导页	/onboarding	首次使用获取偏好
首页	/ 或 /home	推荐 + 问答
规划页	/plan	我的规划
规划生成页	/plan-generate	AI 生成规划
资源页	/resources	工具/中介资源
个人主页	/profile	用户中心


# 技术架构说明
路由: 使用 expo-router，(auth)、(onboarding)、(tabs) 是路由组
状态管理: 使用 Zustand 管理全局状态（认证、用户偏好、规划数据）
数据请求: 使用 @tanstack/react-query + Supabase
AI 规划: 单独的服务层处理 AI 生成逻辑
